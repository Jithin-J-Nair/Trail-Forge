# TrailForge agent skills

Installed for reconstruction (**TF-34**, continued from TF-22). Cursor project skills live in `.cursor/skills/` (alongside existing `.cursor/rules/`). Cursor also discovers `.agents/skills/`; this repo standardizes on `.cursor/skills/`.

**Method:** shallow sparse clones of upstream repos; copy only selected skill folders. No `npx skills add` dumps, no `npx impeccable install`, no blind script execution. One path patch in `ui-ux-pro-max` so its search CLI resolves under Cursor (see below).

**Karpathy trim:** keep the 12 curated skills only. Inside `ui-ux-pro-max`, drop upstream unit tests, catalog-refresh JSON, `validate_data.py`, and unused stack CSVs (keep `react`, `threejs`, `html-tailwind`, `nextjs`, `shadcn`). Drop Codex `tdd/agents/` and redundant vercel README/metadata. Vendored skill trees are listed in `.prettierignore` so CI does not reformat upstream text.

**Gap:** none of the evaluated sources ship a dedicated MapLibre, Cesium, or R3F skill. Closest coverage is `ui-ux-pro-max` (`--stack threejs`, MapLibre/GIS rows in product + UX data). Treat MapLibre/Cesium as additive spatial options per the product audit; do not invent GIS skills.

### `ui-ux-pro-max` local note

Upstream docs use `${CLAUDE_PLUGIN_ROOT}/.claude/skills/...`. This install patches invocations to `${SKILL_DIR}/scripts/search.py` where `SKILL_DIR` is `.cursor/skills/ui-ux-pro-max`. Example:

```bash
cd .cursor/skills/ui-ux-pro-max
python3 scripts/search.py "immersive 3d city travel" --stack threejs -n 5
python3 scripts/search.py "keyboard focus reduced motion" --domain ux -n 5
```

## Assumptions

- Project-level `.cursor/skills/` is the shared Cloud Agent source of truth (personal `~/.cursor/skills/` does not sync unless the user enables Sync Skills).
- Karpathy already available via Cursor plugin cache; not vendored into the repo.
- No MapLibre/Cesium/R3F-specialized upstream skill existed in the eight sources on evaluation date; Three.js stack data inside `ui-ux-pro-max` is the GIS-adjacent substitute.
